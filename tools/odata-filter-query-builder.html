OData filter query builder

Get items and List rows actions are much faster when the filtering happens at the source instead of in a loop afterwards, but OData syntax is easy to get wrong: eq instead of =, quotes around text but not numbers. Add your conditions and copy the query.

OData Query

ADD CONDITIONS, COMBINE WITH AND / OR
PLUS $select, $orderby, AND $top


      
      
    


    
This builds a single AND/OR group, not nested groups within groups. For deeper nesting, combine two of these queries manually.

  






  

    
How to use it

    
    
      
  1. Add your conditions and choose whether they combine with AND or OR.
    2. 
      
  2. Optionally set the columns to return, the sort order and a row limit.
    3. 
      
  3. In an action with separate fields, paste each part without its prefix: the text after $filter= goes in Filter Query, and so on. For a direct API call, use the whole query string.
    4. 
    

    
Nothing you type here is sent anywhere. The tool runs entirely in your browser.
