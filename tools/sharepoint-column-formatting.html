SharePoint column formatting generator

Column formatting lets a SharePoint list highlight the items that matter, like an Urgent priority in red, without changing any data. The JSON is fiddly to write from scratch. Set the column, the condition and the colour, and copy JSON you can paste straight into the column's formatting panel.

SharePoint column formatting

A conditional background colour, ready to paste into column formatting.


      
      
    


    
Paste this into a SharePoint list column's "Format this column" → Advanced mode.

  






  

    
How to use it

    
    
      
  1. Enter the column's internal name. It can differ from the display name; you'll find it at the end of the URL when you open the column's settings.
    2. 
      
  2. Choose the condition, the value to match and a background colour.
    3. 
      
  3. In the list, open the column's menu, choose Column settings, then Format this column, switch to Advanced mode and paste the JSON.
    4. 
    

    
    
Nothing you type here is sent anywhere. The tool runs entirely in your browser.
