Privacy

FlowNarrate does not run a backend, does not use a database, and does not have a sign-up or login of any kind. Here is exactly what that means in practice.

The tools

Every tool on the tools page runs entirely in your browser using JavaScript. Whatever you type into an expression builder, a JSON schema box, or any other tool stays on your device. Nothing is sent to a server, because there is no server to send it to.

Theme preference

If you switch between light and dark mode, that choice is saved using your browser's local storage so it's remembered next time you visit. This stays on your device and is never transmitted anywhere.

Analytics and cookies

This site does not currently run analytics and does not set tracking cookies. If that changes in future, this page will be updated to say so plainly.

Hosting

The site is hosted on GitHub Pages, which may log standard technical information (like IP addresses) as part of normal web hosting, the same as any website. FlowNarrate itself does not access or use this data.

Fonts

The site's fonts (Source Serif 4 and JetBrains Mono) are stored on this site and load from GitHub Pages along with everything else. Your browser does not contact Google or any other font service.

Contact

Questions about this page can be sent via LinkedIn.
