# antislop audit 002: the five skills

Date: 19 Oct 2026
Mode: AFTER. Simone asked for every finding to be fixed, so the findings and their fixes are both recorded here.
Skills: antislop core plus `antislop-ui`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile` and `antislop-code` (v3.2.21, installed in `.claude/skills/`)
Scope: all 23 pages, `assets/tools.css`, `assets/tools.js`

## How it was checked

- **UI:** searched every page's markup and CSS for the skill's tells (status dots, eyebrow labels, typed capitals, card grids, unused decoration).
- **Copywriting:** pulled the visible text of every page (about 12,000 words). Read the posts and main pages in full, and searched all of it for the skill's vocabulary and rhythm tells.
- **Human:**
  - Tabbed through every page in light and dark mode and confirmed each focused element shows an outline.
  - Measured form-field borders against their background.
  - Fed empty and invalid input to the JSON and SVG tools.
- **Layout and mobile:** checked overflow at 320, 375, 600, 768, 1024 and 1280px, and tap-target sizes at 375px.
- **Code:** read every comment in `tools.js`, `tools.css` and the inline styles and scripts.

## What already passed

- **Copy:** the posts read as written by a person. They're specific, with real error messages, real IDs, a tested 5,739-character link and honest limits ("It only catches people who've actually turned an auto-reply on"). No buzzwords, signposting, chatbot closers, fake candour or generic conclusions. Per the copywriting skill's "preserve these" list, the posts were left alone.
- **Keyboard:** every focusable element on every page shows a visible outline in both themes.
- **Form fields:** borders use `--ink-soft`, well above 3:1.
- **Tool error states:** the JSON tools already had text error messages.
- **Code:** most comments explain why (encoding rules, browser quirks, accessibility reasons), as the code skill asks.
